# موقع الوادي كلادي — Wadi Clay

## الملفات المهمة
| الملف | شو فيه |
|---|---|
| `index.html` | الموقع الرئيسي |
| `admin.html` | لوحة التحكم (إضافة/تعديل/حذف المنتجات والصور) |
| `assets/js/config.js` | **رقم الواتساب + رابط الإنستغرام + ربط Supabase** — هذا الملف الوحيد اللي بتعدله |
| `assets/img/logo.png` | حط اللوجو هون بهذا الاسم بالزبط |
| `supabase/setup.sql` | إعداد قاعدة البيانات (مرة وحدة) |

## ١) اللوجو
احفظ صورة اللوجو باسم `logo.png` داخل المجلد `assets/img/`. بيظهر تلقائياً بالهيدر وشاشة التحميل ولوحة التحكم.

## ٢) رقم الواتساب
افتح `assets/js/config.js` وغيّر:
```js
whatsapp: "9627XXXXXXXX",
```
(بدون + وبدون مسافات)

## ٣) تفعيل لوحة التحكم (مجاناً على Supabase)
1. ادخل على supabase.com واعمل حساب ومشروع جديد (الخطة المجانية Free).
2. من القائمة: **SQL Editor → New query**، الصق محتوى ملف `supabase/setup.sql`.
   - قبل التشغيل غيّر `admin@example.com` لإيميل البنت اللي رح تدير المنتجات.
   - اضغط **Run**.
3. من **Authentication → Users → Add user**: أضف نفس الإيميل مع كلمة سر قوية (فعّل Auto Confirm).
4. من **Authentication → Sign In / Providers**: اطفي **Allow new users to sign up** (عشان ما حدا غريب يعمل حساب).
5. من **Project Settings → API**: انسخ **Project URL** و **anon public key** وحطهم في `config.js`:
```js
supabaseUrl: "https://xxxx.supabase.co",
supabaseAnonKey: "eyJhbGciOi...",
```
6. افتح `admin.html` وسجّل دخول. أي منتج بيتضاف بيظهر على الموقع فوراً.

> المفتاح العام (anon) آمن يكون بالموقع — الحماية من قواعد قاعدة البيانات: فقط الإيميلات الموجودة بجدول `admins` بتقدر تعدل.
> **لا تحط أبداً** مفتاح `service_role` بأي ملف بالموقع.

## ٤) طريقة استخدام لوحة التحكم (للأدمن)
- **+ منتج جديد**: صورة، اسم عربي/إنجليزي، السعر، السعر قبل الخصم (إذا في عرض)، التصنيف، السعة، الوصف، شارة مثل «جديد».
- الصورة بتنضغط تلقائياً قبل الرفع — بتقدري ترفعي مباشرة من كاميرا الموبايل.
- **متوفر**: اطفيها لما يخلص المخزون (بيظهر «نفد من المخزون» وما بينطلب).
- **ظاهر**: اطفيها لإخفاء المنتج بدون حذفه.
- **الترتيب**: رقم أصغر = يظهر أول.

## ٥) النشر على الإنترنت (مجاناً)
الموقع ملفات ثابتة، بينرفع كما هو على Netlify أو Vercel أو Cloudflare Pages أو GitHub Pages — اسحب المجلد كامل وخلص.

## التشغيل محلياً
من مجلد المشروع الرئيسي، شغّل السيرفر `alwadi-clay` (موجود في `.claude/launch.json`) أو:
```
powershell -ExecutionPolicy Bypass -File alwadi-clay-site/serve.ps1
```
ثم افتح http://localhost:4180
